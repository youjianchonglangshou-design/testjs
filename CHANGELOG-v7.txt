v7：新增 GitHub 風格拖曳上傳板塊

新增：
- 畫面上固定顯示大型拖曳上傳區
- 可一次拖入多個檔案
- 拖曳進入時板塊會變色提示
- 點擊板塊也可以開啟多檔選擇視窗
- Enter / Space 鍵也可以開啟選檔
- 板塊會顯示目前上傳目標：ROOT 或目前子資料夾
- 上傳時板塊自動進入忙碌狀態

沿用既有上傳引擎：
- Contents → Read and write
- 同名檔案會詢問是否覆蓋
- 可上傳到目前所在 GitHub 資料夾
- 上傳完成自動刷新

保留：
- 讀取 Repository
- 核取刪除
- 即時同步
- 整包 ZIP 下載
- Token 權限呼吸提示
- 權限示意圖浮層
